# tools/

Repeatable steps of the offline-client workflow, so no session re-types them. Each script
has `--help`. Run from the Trunk root. Python 3, standard library only.

| Script | Replaces | Skill |
|---|---|---|

| `logs.py` | grepping ErrorLog.txt / offline_*.log and guessing whether they are from the new exe | x2-check-logs |

| `bytepatch.py` | ad-hoc Python byte patches of CP949 sources | x2-byte-edit |
| `docsection.py` | reading a 750 KB plan doc "in full" | x2-phase |

| `mdscan.py` | (older) reading a CrashRpt minidump against X2.map | - |

| `junecensus.py` | the rough one-off scripts that counted `June`-named functions, members, locals, constants and the March functions June code calls (plan `june-march-divergence`, D0a): `python tools/junecensus.py` scans X2Lib / KTDXLIB / X2 (+ the shared headers that name June; per-file cache in `.build/junecensus`, ~15 s) and writes `june2017_re/diverge/names.tsv` (every identifier with `June` / `JUNE_` / a June address / a phase tag, never `SERV_IRUHADEV_*`: kind, file, class, enclosing function, flag at the definition, June address, March twin in the same class + `twin_check` against funcmap.tsv, uses) and `callees.tsv` (every function called from a June-named body or the live branch of a defined June flag: owner class, origin march / ours, call sites, funcmap status `same` / `hint: <word>` / `none`), then prints the census table beside the plan Context; `--check-twins`, `--file PATH`, `--gate` (exit 1 while a June-named identifier remains: the C5 / D2 gate), `--no-scan`, `--rescan`, `--jobs N` | x2-phase (`june-march-divergence`) |
| `junebinary.py` | hand counts of the June 2017 binary (plan `june-census`, V1): `python tools/junebinary.py` joins `june2017_re/census/functions.tsv` (V0) with `funcmap.tsv`, the March tree (`Class::Method` definitions, `SERV_IRUHADEV_JUNE_*` blocks) and the backlog / plan docs, and writes `coverage.tsv` (bucket studio / library / crt-stl / unknown + basis, status, owner per function) and `coverage_by_file.tsv`; `--check` (`RESULT:` line), `--holdout` (precision of the block rule), `--sample N` (guarded rows for a hand check), `--summary` (not `junecensus.py`, the D0a tool) | x2-phase (`june-census`) |
| `junecollapse.py` | applying one batch of `june2017_re/diverge/collapse_map.tsv` (plan `june-march-divergence`, C0): `python tools/junecollapse.py apply C1 [--dry-run] [--files F ...] [--only OLD ...] [--report out.tsv] [--out-dir DIR] [--base REV] [--allow-existing] [--scope-locals] [--map TSV]`, `--selftest`. Byte-level, CP949-safe (comments and literals masked, edits are splices of the original bytes). `merge` moves June's body into March's twin under the flag (`#ifdef F June #else March #endif F`; the port's `{ #ifdef LIVE June_X(); } #else ... }` delegating wrapper is rewritten under its LIVE flag), deletes the June definition and header declaration, collapses plain `#ifdef F June_X(..) #else X(..) #endif` wrappers and renames the rest; `rename` refuses a name the class, its bases (read from the headers) or the touched files already have (`--scope-locals`: a local is refused only when its new name is used in the same function, column-0 braces, on a branch the old name can meet); `enum` / `namespace` / `class` / `lua` / `file` / `drop` / `keep` are the matching rewrites. A name shared by rows of several classes is renamed only in the row's own file and header. Anything else (inline header definition, braces split across `#if`, differing default arguments or parameter types, a note naming a hand shape, a mixed-flag call site) is listed for `bytepatch.py`. After each file: `flagcheck.strip` flag-off equivalence against the base revision (every `SERV_IRUHADEV_JUNE_*` undefined, byte for byte) and an encoding-class check; one failing file means nothing is written (the C phases C1-C5) | x2-phase |
| `junediverge.py` | the June / March divergence gate (plan `june-march-divergence`, D2): `--check FILE...` (exit 1 on a June-named / address-named / phase-tag identifier defined in a file, a PvP-only game-type test inside June code (June `322cc1a0` = `GetIsNowPVPCorrectionGame()`), or a June-code call to a `replace` row of `tools/data/june_march_divergent.tsv` that is not done; June code = the ON branch of a defined `SERV_IRUHADEV_JUNE_*`, never the `#else`), `--check-all` (every source file holding a June flag, ~25 s), `--list` (names to avoid, idiom rows, open `replace` rows), `--open-rows`, `--selftest` (pinned `d4e8edc6` VioletMage + fixtures); allow-list `tools/data/june_diverge_allow.tsv` (`file`, `function`, `name`, `reason`) | x2-phase (every phase's Finish) |

Shared state (every worktree deploys into the same game directory):
`%LOCALAPPDATA%\x2build\build.lock` and `last_deploy.json`. Per-tree build logs: `.build/logs/`.
Paths can be overridden with `X2_GAME_DIR` and `X2_BUILD_STATE`.

Validation done when they were written (2026-10-04):
- `build.py`: incremental build of all four projects; deploy of an identical exe; lock wait,
  lock timeout (exit 75) and stale-lock recovery; deploy refused while the game ran.
  2026-10-18: build coalescing (`last_build.json`, 13 cases incl. failed / `--only` / other
  config / older exe) and X2 with `BuildProjectReferences=false` after both libs built in the
  same run (the X2 step had been rebuilding both libs, ~10 min); STALE LINK guard.
- `flagcheck.py`: `--selftest`, and reproduces three verdicts earlier reviews recorded by hand
  (TEMPLET_PARITY vs `9133871^` including X2Game.h's 19 EOL-mismatched lines; BEHAVIOR_PARITY
  part 1's 3 blank lines in X2BuffFactor.cpp; OFFLINE_AUTH_LEVEL's one blank line in each
  X2OfflineDB file). Phase 6 (`JUNE_BUFF_NEW_SKILL`) passes.
- `bytepatch.py`: CRLF insert/replace in X2GUUser.cpp and LF insert in the LF-native
  X2UserSkillTree.cpp (scratch copies); hex anchor on a Korean line; ambiguous anchor refused
  with nothing written; high-byte count and encoding class unchanged.
- `.claude/hooks/encoding_guard.py`: blocks Edit/MultiEdit/Write on CP949 files (forward- and
  backslash paths), passes ASCII/UTF-8 files and new files, fails open on bad input; the post
  check reports a lost BOM. It runs once it is registered in `.claude/settings.json`.
