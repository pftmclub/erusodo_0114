# Elesis June-side facts, binary half. Read-only Ghidra / raw-exe collection, 2026-11-11 (planning session char-elesis). Model: june2017_re/char_ara/plan_june_side.md section 1

Method: Ghidra `list_functions` (55,556 functions, same count as Ara's file) + `xrefs_to` / `get_function_by_address` / `decompile_function`; vtables, thunk tables and call scans read straight from `unpacked_x2.exe` (`F:\elsword stuff\elsword_2014\els_2014\237311\14JUN17\data\unpacked_x2.exe`, file offset = va - 0x31aa0c00); uncarved code read with `charport_adis.py` through a scratchpad wrapper that sets `CLASS_RANGE['elesis']` in memory (the repo copy is not edited: `elesis` is still missing from its `CLASS_RANGE`). Nothing was written to Ghidra. Sizes marked `~` come from a ret-plus-padding heuristic for uncarved code.
