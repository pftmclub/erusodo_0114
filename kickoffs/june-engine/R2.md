## R0 amendments (2026-10-16)

Read `JUNE_ENGINE_REMAINDER_PHASES.md` "R0 map (2026-10-16, Opus 5.5)" and `june2017_re/r0_renderer_contract.tsv` (funcmap `Engine R0`). They change this task as follows:

- **`+0x58` is device caps** (`PixelShaderVersion >= 3.0` in the ctor), not an option. Also port `+0x82` (mipmap cap -> `MIPFILTER`),
  `+0x84` / `+0x88` (anisotropy; `SetAnisotropy` `3242ed40`; the `OnResetDevice` sampler block).
- **There are no `RenderParam` rim members and no Lua readers for them.** This line of the original task is wrong (the key
  `useRimLight` belongs to the option UI). Instead:
  - `RenderParam` gains `int` `+0x9c` (world cartoon index) and `+0xa0` (world rim ramp). Both go before `bAlphaTestEnable`, which
    moves `+0x9c` -> `+0xa4`.
  - `RenderParam` grows by 8 bytes: grep for `sizeof( RenderParam )`, `memcpy` and arrays first.
  - The five fills (user, square / agit unit, pet, NPC, riding pet: tsv `rpfill`) copy `CX2World +0x1a4 / +0x1a8`. Add
    `CX2World::SetCartoonTextureIndex` (`327fb200`) and port June's `SetRimLightTextureIndex` (`327fb220`), which supersedes the
    Ranox stand-in under this flag.
- **`EFFECT_PARAMETER` is renumbered.** June inserts 15-24 after `g_fEye`, so March's `g_fColor` .. `g_iShaderIndex` (15-18) become
  25-28. Replace the whole enum and name table under the flag.
- **The rim enable is an option, read per frame.** Port the chain:
  - `CX2GameOption` keys `RIM_LIGHT`, `USE_VIEW_INDEPENDENT_EDGE`, `ANISOTROPIC_FILTER_SAMPLE`, `USE_ENV_BOX`, read in the load, written
    in the save, with June's defaults.
  - The apply (`32421110`) sets renderer `+0x80` / `+0x81` and calls `SetAnisotropy`.
  - `CX2Main` vslot 1 (`31d90300`) calls `SetRimLight( option RIM_LIGHT )` every frame.
  - The UI stays with Stage 9. Check the user's answer to plan open question 4 (June default off vs a stand-in) before coding.
- **Setters:** follow the tsv `param` rows (`BeginRender` `31d3cf80`, `OnFrameRender` `31d3e7d0` and the `DrawFrame` copy at
  `31d3f17a`), including the env-box branch. It stays off because `+0x80` needs an env box, and R3 may be dropped (open question 5).
- **`COLOR_WIREFRAME`:** not in June's technique table (`337299c0` has 19 entries). Do not add it.
- **Play-test:** set `RIM_LIGHT = TRUE` in the game dir's `GameOptions.lua` for the rim-lit unit check (white rim by default; blue
