   studio number.
3. **Fairness.** Add `droptable.py simulate` and run it on one Lanox and one Elysion dungeon and one field of each, against Behemoth
   Heart / Sander Field 03 (15 % gate in "Design").

   simulate figures. State `decision` in STATUS until answered; record the answers in the sheet (`source = user <date>`).
