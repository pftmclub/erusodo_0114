## Task

Do tasks 1-6 of "Phase 0 - Census, reach, June check". This phase has no code, no flag and no build.

1. **Census.**
   - Decompile the stage scripts that carry `MONSTER_GRADE` into the scratchpad with
     `./elstools` (`mar-2014`). 208 of them are bytecode. Trust a file only at its
     live-manifest size.
   - Write `OFFLINE_MONSTER_GRADE_CENSUS.tsv`.
   - Report the grade counts, the dungeons with no grade-1 NPC, and the server's
     `bScriptCheck` mismatches.
2. **Reach.**
   - Count the grade-1 dungeon NPC IDs that have an ExtraNPCStat row.
   - **If that count is zero or small, stop and tell the user before doing anything else.**
   - Otherwise name the Phase 1 play-test target: dungeon, boss, a socket item with boss
     damage, the dev-console commands, and the character and job.
3. **June, in Ghidra.**
   - Check `327edb60`, `327ef570` and `327ef71d`.
   - Does June's dungeon `CreateGUNPC` also set `m_eMonsterGrade`?
   - Is the grade set before the scan-rate read?
   - Add funcmap rows for the answers.
4. **Battlefield data.** Confirm the `SPAWN_GROUP_ID` loader bug. List the middle-boss rows,
   the `SPAWN_ID > 100` rows and any raid fields.
5. **Reward inputs.** Check items 70057 and 70058, where the attribute count comes from,
   whether `fDungeonFactor` reaches the item lottery, and the offline coins.
6. **Kill-all boss rule.** Is it reachable in play or not?

**Done means:**
- the census `.tsv` is committed;
- "Phase 0 - Done" is written, under ~60 lines, with long tables in the `.tsv`;
- `1.md`, `2.md` and `3.md` in this folder are amended with the findings: the target, June's
  `SetMonsterGrade` answer, the raid fields, and the reward inputs;
- the STATUS rows are updated.

The phase is not finished until the user has seen the reach number.
