`june_item_kim/`.

1. **Reachable-item diff, March vs June**, by id. The id sources are:
   - the save, read-only: `sqlite3` with `mode=ro` on `<game dir>\els_db.sql`;
   - `GBASE_ITEM` (`X2Lib/Offline/X2OfflineInventory.cpp:1202+`);

   - `X2OfflineClassChangeSeed.h`;
   - the staged drop, static-drop and cube tables;
   - `ShopItem.lua`, `ItemExchangeTable.lua`, `ManufactureItem.lua` and `ItemConvertTable.lua`.

   **List save-breakers on their own:** an equipped item whose equip position or unit class changed.
2. **Enum-range census** against March's limits, from `X2Unit.h`, `X2Item.h` and the staged `Enum.lua`.
3. **Cross-table ids:**
   - buff factors against the staged `Enum.lua`;
   - socket, random-socket and set options against `OptionItemData.lua` and `SocketOptionForm.lua`.
4. **Asset census:**
   - the reachable set first, then all ids;
   - against `kom_contents` and the staged files.
5. **Code census.** List every March array indexed by a templet field, and every loop over all items at startup or UI build. Give each
   a proposed action: guard + skip + log, or extend.
6. **Memory headroom.**
   - Check `/LARGEADDRESSAWARE` for `US_SERVICE` in `X2/X2_2010.vcxproj`.
   - Estimate the peak transient for the 67.5 MB member.

**What K0 changed (2026-10-07; details in "Phase K0 - Done" and `june_item_kim/k0_record_map.tsv`):**
- `kim.py` already decodes both layouts, including June's pools. Use its subcommands; do not re-derive offsets.
  - Reachable diff: `kim.py diff <March> <June> --ids <file> --summary`.
  - Enum census: `kim.py census <kim> --field <name>`, where `--list-fields` gives `extra_key`, `special_ability_type`,
    `flags_bit7` and `flags2_bit0..3`.
  - Asset census: `kim.py assets <kim> --ids <file>` or `--all`.
- Add to the enum census (task 2):
  - item type 14 is June's `IT_CUSTOM` (1,207 items, Stage 12);
  - special-ability types 40-52: March's `SAT_END` is 40, June's is 53;
  - Extra keys 10-13 (Lu, Ciel, Rose, Ain);
  - flags bit 7, which is PvP-equip in June and HideSetDesc in March.
- Add to the code census (task 5), as sites that K2 changes rather than guards:
  - every reader of `GetStatData()`: June's stat pool is 7 floats and Def sits at [5]/[6];
  - `GetStatRelLVData()`: the sixth byte;
  - `GetHideSetDesc()`: flags2 bit 1 in June;
  - every loop to `MAX_MODEL_COUNT_A_ITEM` and every array sized by it: 6 becomes 8;
  - every caller of `GetFrameOffset` / `GetRenderScale` / `GetRenderRotate` / `GetCommonItemModelName` / `GetCommonItemXETName`:
    June remaps unit type to an Extra key and takes a Lu/Ciel bool;

  - Confirm that June's `SPECIAL_ABILITY_TYPE` 0-39 and `ITEM_TYPE` 0-13 have the same names at the same numbers as March's
