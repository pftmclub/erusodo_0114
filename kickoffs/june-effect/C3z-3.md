## The problem

entries are still March's:
- `DungeonData.lua` (data035): stage lists, time limits, levels, names, entry rules;
- `DungeonEnum.lua` (data036): kept merged because June's drops 59 dungeon names that March's C++ still uses.

The user's goal (2026-10-10) is to update the old dungeons to what June has.
