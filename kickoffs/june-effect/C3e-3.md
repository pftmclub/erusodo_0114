## Task

C3e found what bit `0x400000` (A, SyncData `+6`) is for.

- StateChange `320348c0 @32034b37-32034b4a` sets A when its direct-change re-simulation leaves Future stateChangeNum (`+0x7e39`) more
  than one ahead of Now (`+0x80d9`). DoStateEndStartFuture `31fe6a40 @31fe6aab` clears it.
- DoFrameMove `3206d770 @3206fa63-3206fd42` reads it on **other** users. It ticks two per-attacker hit-stop lists (`+0x85a4`, `+0x85b4`;
  16-byte entries {time, ?, attacker UID}, capped at 1000, trimmed by 500) and erases an entry whose attacker has A set. The attacker is
  looked up through game vslot `0xa0`, a user by UID.
- The lists are filled by June's SetStopTime / SetStop2Time (`31ffe4f0` / `31ffe750`). Those take an attacker and a force flag; March has
  `SetStopTime( float )` only (`X2GUUser.h:1578`).

Map, for a port phase:

1. **The signatures.** Map both vfuncs (vslots, the second argument, the attacker / force arguments), the `+0x7dc8` early return, and the
   NPC overrides.
2. **Every caller.** Cover the user and NPC hit paths, CEffect and class code, against March's `SetStopTime` / `SetStop2Time` callers.
   Class-only callers go to the checklist.
3. **The tick.** Map DoFrameMove's tick / erase / trim. `+0x7df4` / `+0x7df8` are set to the last entry's time: say whether they are
   Future `fStopTime` / `fStop2Time` and how March's own decrement (`X2GUUser.cpp` DoFrameMove, the `fStopTime` block) changes.
4. **Reach offline.** Offline the attackers are NPCs (the AI-party bots are `CX2GUNPC`), so the A lookup never matches. But the per-attacker
   lists still decide the hit-stop. Say what the local player feels differently once ported.

Exit: funcmap rows `Effect C3e-3`, and a port phase with its STATUS row, flag and kickoff that follows June. A itself joins that port
(bit `0x400000`, 1 byte, 4th on the wire).
