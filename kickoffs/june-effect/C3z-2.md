## The problem

The C3x play-test, 2026-10-10 13:54, ran Elder Druid Forest Normal (30070), a June bytecode script. The offline emulator parsed
10 / 13 / 3 NPC cases (`X2DungeonSubStage.cpp` `New_LoadNPCData`) and spawned 1 / 1 / 0, the box only, so the dungeon cleared itself.

The 6 monster ids are June-only, so they read nil in March:
- `NUI_ANGER_FOREST_KNIGHT` 1608, `NUI_ANGER_FOREST_FAIRY` 1609, `NUI_CURSE_WISP` 1610, `NUI_FOREST_DARK_MAGICIAN` 1611,
  `NUI_ANGER_FOREST_ENT` 1613, `NUI_ELDER_DRUID_FOREST_GATE` 1614.
- They are missing from March's merged `data036 Enum.lua` `NPC_UNIT_ID` and from `data037 NPCTemplet.lua`; both files are kept merged.

Other old dungeons that June re-populated probably have the same gap.

1. **Census.** For every `NUI_*` that a dungeon script in kom_contents names, record:
   - whether it is in March's `NPC_UNIT_ID`, and whether its value equals June's;
   - whether March's NPCTemplet has a row for it;
   - June's row (`june_src_fixed/data037_kom/NPCTemplet.src.lua`);
   - whether its `LUA_FILE_NAME` unit script and `MOTION` mesh are in kom_contents (`npc_mesh_census.py` closes the mesh side);
   - which dungeons use it.

   Write it as a TSV under `june2017_re/`.
2. **Enum.lua:** add June's value for each missing id.
   - Check every value against March's `NPC_UNIT_ID` first. On a collision, hand the choice back to the user, as C3x did for world 33.
   - A name whose value differs between March and June is a finding: March's C++ may own that number. Do not renumber silently.
3. **NPCTemplet.lua:** convert it with `/x2-lua` if it is still bytecode (core list, kept merged), then add June's rows verbatim for the
   missing ids.
4. **C++:** check whether anything bounds or switches on an NPC id: `NUI_END`, `CX2UnitManager` lookups, the offline emulator's
   NPC creation, and the drop and exp tables.
   - A June id past a C++ bound needs the bound raised under a flag.
   - Missing drop or exp rows: name the server Lua the user packs; do not invent rows (CLAUDE.md server-Lua rule).
5. Stage any missing unit scripts or meshes (`adopt-june`, `stage-june`). Pack data036 / data037, and ask before every copy.
