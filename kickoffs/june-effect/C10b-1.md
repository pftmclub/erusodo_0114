1. **`CX2GameUnit::GetHpRateDamage( float* pOut, const DamageData* )`** (June `32273e80`).
   March already parses `HP_RATE_DAMAGE_TYPE` / `_VALUE` into DamageData (Phase 8c, `X2DamageManager.cpp`).

   - Type 2: `*pOut = GetMaxHp() * value`.

   - Otherwise, and for any other type, leave `*pOut` alone. It overwrites; it never adds.
2. **`CX2GameUnit::GetFinalDamage` site** (June `32286930..322869aa`).
   - Defender = `pAttDamageData->optrDefenderGameUnit`.
