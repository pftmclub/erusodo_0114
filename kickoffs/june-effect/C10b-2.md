## Task

Port June's effect-alpha option engine onto March. Name new members after the June concept, in March's style,
e.g. `m_byEffectAlphaCondition`. Never port an offset.

1. **Storage (KTDXLIB).** `CKTDXApp` gets three floats, default 1.0 (`31c17ed0 @31c18ddb`).
   - `SetEffectAlpha( BYTE, float )` (`31be2a90`) clamps to [0.1, 1.0]; 2/3/4 are my / my team / other team.
   - `GetEffectAlpha( BYTE )` (`31be2b00`) returns 1.0 for anything other than 2/3/4.
   - Name the enum after June's `APPLY_EFFECT_ALPHA_CONDITION_BY_OPTION` (AEACBO_NONE 0 .. ANOTHER_TEAM 4).
2. **Load and save.**
   - `CX2GameOption::OpenScriptFile` (`324214a0`) reads `MY_EFFECT_ALPHA`, `MY_TEAM_EFFECT_ALPHA` and
     `ANOTHER_TEAM_EFFECT_ALPHA`: float, default 1.0, then the setter.
   - `SaveScriptFile` (`3241ef40`) writes the same three in June's format, after `SHOW_AMUSEMENT_ITEM_DESCRIPTION`.
3. **Category.**
   - `CX2Game::GetEffectAlphaCondition( CX2GameUnit* )` (`322d4d10`).
   - "Is mine": user = `IsMyUnit()`; NPC = owner UID == my unit's UID (`3276b2b0`).
   - The user override (`31fd8350`) forces 1 in `USI_START`, `USI_WIN` and `USI_LOSE`, or in
     `USI_RIDING_WAIT_HABIT` and `USI_RIDING_WAIT` while `GetRidingOn()`. June numbers these 9/11/12/75/76; use
     March's enum names.
   - The NPC override is a no-op.
4. **Owned NPCs.**
   - `CX2GUNPC::SetOwnerGameUnit` stores the owner's category (`327765e0`); the NPC getter returns it (`32755a90`).
     The user and base getters return 0.
   - NPC body render-param alpha (`3276fae0..3276fb35`; pin the March host).
   - `CX2GameUnit::Weapon` render-param alpha (`32273230`).
5. **Effect readers.**
   - EffectSet `_CreateEffectSetInstance` (`321e1bf0`) and `OnFrameMove_CreateEffect` (`321ee600`). The EFFECT value
     counts only as 1; it hands the category to the CEffect, mesh or particle.
   - CEffect: the ctor (`@31f7c2df`, 0 -> category), `OnFrameMove` (main mesh, every frame), `SetParticleData`, and
     `AttackResult` (hit effect set, unconditional).
   - March's existing `m_iApplyEffectAlphaConditionByOption` members (EffectSet, CEffect) are the stores. Retire their
     rule-5 "unsupported" log lines under the new flag, keeping the old lines in `#else`.

   - The blend rule is `31ceefb0`.
