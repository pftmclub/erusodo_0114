## Task

Port June's hit-stop mechanism whole, under the new flag, with March's code in `#else`. Every fact and address below is in the funcmap rows
`(C3e-3)` and the caller table.

1. **Signature.**
   - Change the CX2GameUnit pure virtuals and the CX2GUUser / CX2GUNPC overrides to
     `SetStopTime( float fStopTime, bool bDamageDataStop = false, CX2GameUnit* pAttacker = NULL, bool bForce = false )`, and the same for
     SetStop2Time.
   - Grep the whole client for other overrides and callers, Lua bindings included, before deciding the defaults.
2. **User** (`31ffe4f0` / `31ffe750`).
   - **The immune state.** `TIME_STOP_IMMUNE_STATE`: a bool read in CommonStateStart (miss -> false). The early return is `IsMyUnit() &&
     immune && !bForce`. SetStop2Time drops the `!bForce` term.
   - **The lists.** Two vectors of `{ float fTime; UidType attackerUID; }`. The UID is -1 unless the attacker is a `GUT_USER`.
   - **The setters.** No direct write of fStopTime / fStop2Time any more. Keep the linemap `max`.
3. **OnFrameMove** (`3206eaf0 @3206fa63-3206fd7c`): replace March's gate in the `IsLocalUnit()` block.
   - **When.** Run the tick per list before the gate.
   - **Trim.** Above 1000 entries, erase( begin, end - 500 ).
   - **Each entry.** `-= fElapsedTime`, clamped to 0, and kept at 0.
   - **Erase.** Erase an entry when `g_pX2Game->GetUserUnitByUID( uid )` has Now A set. Set the stop time to 0 if that empties the list.
   - **After the loop.** If the list is non-empty, the stop time is `back().fTime`; if empty, decrement it and clamp it to 0.
   - **The gate.** Then the gate, with no decrement in its else branch.
4. **NPC** (`32772aa0` / `32772c10`).
   - The return test is `bDamageDataStop ? m_bImmunityDamageDataStopTime : m_bImmunityTimeStop`.
   - Read `IMMUNITY_DAMAGE_DATA_STOP_TIME` next to March's `IMMUNITY_TIME_STOP` LUA_GET_VALUE, default false.
5. **Callers.** Give every engine caller June's arguments: caller-table rows 1-2, 4-9 and 11-19, the CX2Game Stop helpers included.
   - The DamageReact super-armor branch (rows 3 and 10) is C3e-5's; leave March's condition as it is.
   - Class rows 21-23 are checklist 7p.
   - Ain (row 24) is backlog Stage 8.
6. **A** (bit `0x400000`, 1 byte, 4th on the wire after bit 4).
   - Add it to SyncData, its push / pop copies and the UDP encode / decode.
   - Set it in StateChange's `bDirectChange` receive-replay loop, after each DoFrameMoveFuture: `(signed char)` Future stateChangeNum >
     Now + 1.
   - Clear it in DoStateEndStartFuture where stateChangeNum is stored.
7. **JUNE_BUGS rows** for the quirks you keep:
   - entries never drop at 0;
   - the newest entry, not the max, sets the stop time;
   - SetStop2Time ignores `bForce`;
   - CEffect::AttackResult passes `bDamageDataStop = false` where the unit AttackResults pass true;
   - the NPC's damage-data stop no longer checks `IMMUNITY_TIME_STOP`.
8. **Log.** Log once per stop under `JUNE_FX C3e-4`, behind a `_DEBUG` flag: the stop time, which list, whether the immunity returned, and the NPC
   key that blocked.
